# ColorBends component

This workspace contains a React `ColorBends` component at [src/components/ColorBends.jsx](src/components/ColorBends.jsx#L1-L200) and a small demo in [src/App.jsx](src/App.jsx#L1-L60).

To run the demo locally (Vite):

```bash
npm install
npm run dev
```

The demo mounts to a `#root` element created at runtime. If you want to integrate the component into your existing static `index.html`, import and render `ColorBends` inside your application entry.
